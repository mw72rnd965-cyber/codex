# EDITH for Mac

Download **EDITH-Mac.zip** from this branch. On GitHub, open the ZIP file and click **Download raw file** (the download arrow). Then open Finder → Downloads and double-click the ZIP.

Inside the extracted folder, open **EDITH → mac → READ ME FIRST.txt**. Install Node.js 24 LTS, Python 3.13 (or 3.12; not 3.14+), and Ollama using its links. Then double-click **Start EDITH.command**.

First launch downloads the free Qwen3 8B model and Kokoro voice and opens the local app in Safari. Keep the Terminal window open while using EDITH. Allow roughly 10 GB free disk space; 16 GB RAM is recommended.

The app build and tests passed in Linux. The launcher was syntax-checked; actual macOS execution has not been verified.
